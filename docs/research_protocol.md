# Research protocol

## Example hypotheses (test, do not assume)
- H1: Mean CAR around regulatory announcements differs from zero.
- H2: Absolute abnormal returns differ across event categories.
- H3: NLP sentiment is associated with the sign of short-window abnormal returns.

## Record for each run
Dataset/source and download date; market/date range; event inclusion rules; timestamp-to-session mapping; ticker mapping; adjusted-price convention; windows; benchmark; missing-data rules; sample size and exclusions; model/taxonomy versions; effect size; confidence interval; p-value; multiple-testing correction.

## Bias controls
Use publication time rather than later update time when available. Do not use future information for classification. Deduplicate syndicated stories. Disclose survivorship bias. Account for non-trading hours and market holidays. Overlapping event windows and confounding news require explicit handling. Statistical significance is not the same as economic significance or causality.
